Uno sconto percentuale extra sul totale, per chi ha il codice. Sono visibili nel sorgente del sito: usali come cortesia via passaparola, non come sistema segreto.

Come pubblicare le modifiche

  1. Compila prezzi e codici qui sopra, poi premi "Genera e scarica config.json".
  2. Il browser scarica un file chiamato config.json.
  3. Vai sul repository GitHub del sito, nella stessa cartella dove si trova listino-scarponi.html.
  4. Carica il nuovo config.json trascinandolo nella pagina di GitHub, scegliendo di sostituire quello esistente, e conferma il commit.
  5. Entro qualche minuto il sito mostrerà i nuovi prezzi e codici — nessun altro file va toccato.
